Palette

The colours, and the numbers behind them.

Every colour on this site is a CSS custom property. This page reads them back out of the stylesheet in your browser, resolves each to a real RGB value, and computes the WCAG 2.1 contrast ratio for each foreground/background pair the site actually uses. Toggle the theme to audit the other palette.

This is not a certificate. It’s a page that recomputes the same thing the build-time audit does, in front of you, from the same tokens. If a number here disagrees with the stylesheet, the page is the thing that’s wrong.

07Method

Each token is resolved by setting it as the color of a hidden probe element and reading back the computed value, so anything the stylesheet does with color-mix() is resolved by the browser rather than guessed by me.

Relative luminance and the ratio follow the WCAG 2.1 definitions exactly: sRGB channels are linearised, weighted 0.2126 / 0.7152 / 0.0722, and the ratio is (L1 + 0.05) / (L2 + 0.05). No rounding until the last step.

The first time I ran this audit, control borders came out at 1.8:1 — well under the 3:1 minimum, because I’d picked a pleasant-looking grey instead of a testable one. The fix was to darken --border-strong until it passed, in both palettes.
